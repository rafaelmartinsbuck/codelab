# Pacotes de Conversa v2 — Sonnet escreve cada prompt
Formato novo: thread única, sem ficha/arquivo, 1 página Kindle por capítulo.
Cada pacote = 1 conversa nova com o Sonnet. Cole MENSAGEM 1, depois MENSAGEM 2.
Se reprovar no gate, cole MENSAGEM 3 com o critério específico.

## OS 4 CRITÉRIOS DE QUALIDADE (cole isto em TODA conversa, junto da MENSAGEM 1)
Além do gate HR-1..HR-11, todo prompt escrito precisa passar nestes 4 testes:
1. **Formação de bom prompt:** papel na 1ª linha + instrução positiva + UM PASSO
   DE RACIOCÍNIO antes da conclusão ("primeiro releia X, depois conclua Y") +
   formato de saída explícito.
2. **Minimalista, sem enfeite:** nenhuma frase decorativa ou apelo de
   autoridade vazio ("aja como especialista de classe mundial"). Cada linha
   cumpre função; se remover e nada quebra, ela não devia estar lá.
3. **Parâmetro do leitor SEMPRE NO TOPO** do prompt, logo após papel/gatilho,
   nunca no meio ou no fim — antes de qualquer instrução de tarefa.
4. **Groundedness de RH:** toda conclusão cita o fato específico que a
   sustenta; se a evidência for fraca, a IA declara isso (hipótese, não
   conclusão fechada) em vez de cravar um resultado.

# PACOTE 1 — CAPÍTULO 1: Sua força e seu freio
# ══════════════════════════════════

## MENSAGEM 1

Você vai escrever o prompt do CAPÍTULO 1 do livro "Profissional Exponencial".
Este é o ÚNICO capítulo com setup — os demais usam a mesma conversa (thread
única, sem arquivo nem ficha para gerenciar).

REGRAS DO FORMATO (valem para todo o livro):
- Esqueleto fixo da página: título → 1 linha de valor → o que colar (se houver)
  → PROMPT (8-14 linhas) → "DE VOLTA: [1 linha]". Cabe em 1 página Kindle
  (~250-300 palavras a página inteira).
- O prompt tem papel (1 linha) + gatilho de encadeamento (não se aplica no
  Cap 1, que é o primeiro) + PARÂMETROS DO LEITOR NO TOPO (os 3 campos, aqui)
  + tarefa com 1 passo de raciocínio antes da conclusão (2-4 linhas) +
  formato de saída (2-3 linhas) + 1 gancho de aprofundamento (1 linha).
- 3 campos fixos, preenchidos SÓ AQUI no Cap 1, NO TOPO do prompt (os demais
  capítulos não repetem — a conversa já sabe): País, Profissão, Onde quero
  chegar.
- Método: os três lados de uma carreira — Técnico (o que faz bem), Negócio
  (o quanto liga isso a resultado), Pessoas (como se relaciona e influencia).
  Quando algo falta, a causa é: não desenvolveu, não mostrou, ou tem um medo
  travando.
- Boas práticas de prompt: instrução positiva (diga o que fazer), passo de
  raciocínio antes da conclusão, formato de saída explícito, sem jargão
  técnico de IA para o leitor.
- Evidência real (groundedness): a IA usa fatos do CV/LinkedIn, nunca elogio
  genérico. Se faltar dado, pede 1 situação concreta (o que fez, para quem,
  o que não aconteceu depois). Se só vier 1 exemplo, marca o diagnóstico como
  primeira leitura, não conclusão fechada.
- Gancho de aprofundamento: 1 frase oferecendo pesquisar 1 dado real de
  mercado (com fonte) sobre a força do leitor, se ele quiser.

GATE — CORE deste capítulo: HR-1 (evidência real), HR-2 (pede 1 situação se
faltar dado), HR-3 (a ambição do leitor guia a análise), HR-4 (passo da
semana amarrado a trabalho real), HR-5 (causa do bloqueio bem fundamentada),
HR-6 (Triângulo + causa coerente), HR-7 (comportamento, não traço/viés),
HR-8 (passo da semana = marcador), HR-9 (cabe em 1 página, esforço mínimo),
HR-10 (um consultor de RH experiente assinaria este diagnóstico), HR-11
(sem CV real e os 3 campos preenchidos, o prompt não produz nada de valor).

## MENSAGEM 2

TAREFA DO CAPÍTULO 1:
- O que o leitor cola: currículo (arquivo) OU link do LinkedIn + os 3 campos

  (País, Profissão, Onde quero chegar).
- A IA diagnostica: (1) a força do leitor, como 1 frase pronta para usar;
  (2) o lado mais fraco hoje (Técnico/Negócio/Pessoas) + a causa (não
  desenvolveu / não mostrou / medo); (3) 1 passo concreto para esta semana,
  amarrado a uma situação real de trabalho que vai acontecer. Se o leitor
  só deu 1 exemplo, a IA entrega o diagnóstico normalmente, mas marca que é
  uma PRIMEIRA LEITURA (não uma conclusão fechada) — e que vai ficar mais
  forte se ele der mais exemplos depois.
- Formato de saída: as 3 partes acima, curtas e diretas.

# LEMBRETE RÁPIDO
